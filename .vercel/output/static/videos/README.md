# TRUE SELF® Hero Video Directory

Place the cinematic video files here:

- `/videos/hero-cinematic.mp4` (Primary format: MP4 / H.264 / AAC, compressed for web ~3-8MB)
- `/videos/hero-cinematic.webm` (Optional WebM format for ultra-fast modern browser streaming)

The poster fallback is automatically loaded from `src/assets/hero-coastal-sunset.jpg` to prevent layout shifts and display instantly while the video streams or if reduced motion is requested.
